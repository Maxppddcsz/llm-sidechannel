## Usage:
for ROC curves: refer to `privacy`, we provide scripts to test the similarity of one_privacy info and two_privacy info.

Then we can depict the results in `ROC-graph`

For the attack: 
- gptcache_server: provides a trivial end-to-end demo.
    - Please first launch the server.py, client.py, then we can run attacker.py
- attack: basic attack, the eviction prompts will be generated by `eviction_generator.py`
